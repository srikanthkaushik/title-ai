§ 4.2 — PURCHASE TRANSFER / PAPER TITLE / RELEASED LIEN / CLEAN TITLE

SCENARIO:   Transfer Type: PURCHASE
            Origin Title Form: PAPER
            Lien Status: RELEASED (lien existed but has been released)
            Brand: CLEAN (no brand designation)

This section applies when the paper title shows evidence that a lien existed AND
a corresponding release is present. It does NOT apply where a lien notation is present
but no release is found — that is an ACTIVE LIEN requiring supervisor referral (Chapter 5).

─────────────────────────────────────────────────────────────────────────────────────────────

4.2.1  REQUIRED DOCUMENTS

Items 1 through 7 are identical to § 4.1.1 (Purchase/Paper/No Lien). Refer to that
section for the full requirements on each item. The additional requirement for a
released-lien scenario is Item 8.

☐  1. ORIGIN TITLE — as specified in § 4.1.1 Item 1.
☐  2. BILL OF SALE or PURCHASE AGREEMENT — as specified in § 4.1.1 Item 2.
☐  3. MARION FORM TR-1 — as specified in § 4.1.1 Item 3. Block H: check RELEASED;
       attach lien release documentation.
☐  4. MARION FORM TR-2 (VIN Inspection Certification) — as specified in § 4.1.1 Item 4.
☐  5. PROOF OF MARION INSURANCE — as specified in § 4.1.1 Item 5.
☐  6. ODOMETER DISCLOSURE — as specified in § 4.1.1 Item 6.
☐  7. PAYMENT — as specified in § 4.1.1 Item 7 (same fee structure; lien release
       processing fee of $5.00 added only if Form TR-3 is used — see Item 8).

☐  8. LIEN RELEASE DOCUMENTATION — One of the following is required to establish that
       the lien has been fully released:

       (a) ENDORSEMENT ON TITLE FACE — A stamp or handwritten release notation
           on the title face, signed and dated by an authorized officer of the
           lienholder, showing the lien as paid and released. The lienholder's
           name on the release must match the lienholder name shown on the title.

       (b) SEPARATE LIEN RELEASE LETTER — A letter on the lienholder's official
           letterhead, referencing the vehicle VIN, signed by an authorized officer,
           stating that the lien has been fully released. Must include the lienholder's
           name, address, and contact information.

       (c) MARION FORM TR-3 (Lien Release Acknowledgment) — Used when the lienholder
           is registered in Marion DMV's lender system and has submitted the release
           through that system. If Form TR-3 is used, a $5.00 lien release processing
           fee applies (added to total in Item 7).

       Examiner verifies: the lienholder name on the release document matches the
       lienholder name shown on the title face. Any mismatch requires supervisor review.

─────────────────────────────────────────────────────────────────────────────────────────────

4.2.2  ADDITIONAL REQUIREMENTS

EMISSIONS TESTING: Same county/model year rule as § 4.1.2. See that section.

LIEN STATUS CONFIRMATION — IMPORTANT DISTINCTION:
    This section (§ 4.2) applies ONLY to RELEASED liens. An ACTIVE (unreleased) lien
    is not covered here. If a lien notation is present on the title face and no release
    document is found, do NOT use this checklist. Refer immediately to Chapter 5
    (Exception Handling). The examiner shall not ask the customer whether the lien is
    "paid" and accept a verbal confirmation — the release must be documented.

Authenticity concerns: If the examiner has any doubt about the authenticity of the lien
release (e.g., unusual font, inconsistent letterhead, release predates lien date), refer
to supervisor before proceeding.
